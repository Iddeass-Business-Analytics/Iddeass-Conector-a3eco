# Iddeass Conector para a3eco

Conecta **a3eco** con las aplicaciones de Iddeass: a través del conector, las aplicaciones consultan la contabilidad
y contabilizan facturas. Se instala como un servicio de Windows en el servidor donde está a3eco.

Este repositorio sólo contiene los instaladores.

## Descargar

**[Descargar la última versión](https://github.com/Iddeass-Business-Analytics/Iddeass-Conector-a3eco/releases/latest)**

En la página de la versión, en el apartado *Assets*, descargue el fichero `Iddeass-Conector-a3eco-X.Y.Z.exe`. Las
novedades de cada versión están en esa misma página.

## Antes de instalar

- El servidor donde está instalado a3eco, con Windows.
- Permisos de administrador en ese equipo.
- El conector contratado con Iddeass y el identificador de su empresa, que le facilitará Iddeass.

## Instalar o actualizar

Ejecute el instalador y siga los pasos; le pedirá permisos de administrador. Si el conector ya está instalado, el
mismo programa lo actualiza a la versión nueva y conserva su configuración y sus datos. Si algo falla durante la
actualización, vuelve solo a la versión anterior.

Para desinstalarlo: *Configuración de Windows → Aplicaciones → Iddeass Conector para a3eco*.
